# 검토용 HTML 문서

정본입니다. 작업 계획과 작업 결과(검증, 실제 작업)를 사용자가 검토하고 리뷰할 HTML 문서로 만들 때 따릅니다. 사용자가 요청할 때만 만듭니다.

## 무엇을 만드는가

- 결정할 거리를 묻는 문서가 아니라, 전부 결정된 다음의 최종 내용을 담은 문서다. 결정 입력, 회신, 승인 요청 장치는 넣지 않는다
- 작업 계획은 최종 작업 계획, 작업 결과는 최종 작업 결과로 따로 만든다
- 내용은 그 작업에서 확인된 사실만 쓴다

## 형식 요구사항

- 다크 모드를 기본으로 한다
- CSS와 JS는 한 파일에 포함한다
- 표, 차트, 순서도를 활용해 시각적으로 이해하기 쉬운 HTML 문서로 작성한다
- 문서형으로 만든다

위 네 줄 말고는 형식을 정하지 않는다. 전역 CLAUDE.md의 응답 기본값(결론 먼저, 목록 선호 등)은 채팅 응답 규칙이라 이 문서의 구성에 적용하지 않는다. 하드 가드레일(em dash 금지)은 적용한다.
