# drill 모드 출력 골격

질문만 먼저 낸다. 모범답안은 채점 라운드에서만 공개한다.

## 라운드 출력

```
## Round {n}: {축 이름}

**Q{n}-1.** {질문}
**Q{n}-2.** {질문}
**Q{n}-3.** {질문}

답변해 주시면 채점하겠습니다. 라운드를 건너뛰려면 "skip", 끝내려면 "stop".
```

## 채점 출력 (문항별)

```
### Q{n}-{m} 채점

**커버리지**
- ✅ {포함된 핵심 포인트}
- ❌ {빠진 핵심 포인트} : {왜 중요한가 1줄}

**모범답안**
{팩트 시트 기반 답변, 200~400자}

**후속 질문** (❌가 있을 때만, 1개)
{빠진 포인트를 정확히 겨냥한 질문. 명확화 / 가정 탐색 / 관점 전환 중 하나}
```

## 루프 규칙

- ❌가 하나라도 있으면 후속 질문을 내고 답변을 기다린다
- 후속 답변도 같은 형식으로 채점한다
- 축의 모든 문항이 ✅만 남으면 다음 라운드로 넘어간다
- 사용자가 "stop"하면 그 시점까지의 요약(통과 축 / 남은 갭)을 출력하고 Step 5(압박)로 넘어갈지 묻는다

## 라운드 요약

```
--- Round {n} 요약 ---
통과: {문항 목록}
남은 갭: {포인트 목록} → P0 갭 후보
```
