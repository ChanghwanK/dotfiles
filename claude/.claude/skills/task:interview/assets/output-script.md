# script 모드 출력 골격

섹션 순서는 고정이다. 라운드(2~5) 사이에는 구분선과 정지 지점을 둔다.

## 1. 오프닝 (90초 + 5분 확장판)

```
> **면접관: "최근에 하신 {작업 유형} 작업 하나 소개해 주시겠어요?"**

"{결론 한 문장: 무엇을 어떻게 해서 어떤 결과}.

시작은 {발단}이었습니다. 그런데 그때 {문제의 본질 또는 없던 것}.

그래서 {접근 순서: 1 → 2 → 3}.

개인적으로 가장 남은 건 {hook: 틀렸던 것 / 예측이 맞은 것 / 표준에서 벗어난 판단}입니다."
```

**hook 표** (MUST):

| # | 오프닝의 문장 | 유도되는 후속 질문 | 선정 기준 |
|---|--------------|-------------------|----------|
| 1 | "...가 없었다" | 어떤 계측을 왜 골랐나 | 준비 단계 |
| 2 | "...를 증명했다" | 어떻게 증명했나 | 반증 가능한 예측 |
| 3 | "...두 번 틀렸다" | 뭘 어떻게 오독했나 | 자기인식 |
| 4 | "...의도적으로 벗어났다" | 왜 표준을 안 따랐나 | 의도적 이탈 |

## 2. Round 1: 문제 정의 (Q1~Q3)

각 문항: `### Qn. "질문"` → 답변(200~400자, 1인칭) → 필요 시 `> hook 메모`.

```

```

## 6. 꼬리질문 라운드 (why 체인 4~6개 + 도전형 2~3개)

체인 하나의 출력 형식:

```
### 체인 n. 결정: {결정 한 줄}   (출처: {세션/PR})

**Q. {깊이 1 질문}**
{답변}

**Q. {깊이 2: 앞 답변의 구절을 잡아} 그건 왜 그렇습니까?**
{답변}

**Q. {깊이 3}**
{답변}

→ 종결: **{원리 | 제약 | 가치 판단}**. {한 줄 근거}
   (종결 못 하면 "→ 미종결: {끊긴 지점}" 으로 표시하고 8절 P0로 보낸다)
```

도전형은 `### 도전 n. "질문"` → 답변. question-bank 4절에서 2~3개만.
