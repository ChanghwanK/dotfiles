# 팩트 시트 템플릿

답변 작성 전에 확정하고 사용자 확인을 받는다. 각 행에 **출처**를 적는다 (PR #번호 / 코멘트 / 커밋 / 세션 / 사용자 확인).

## 0. 팩트 시트 (외워야 할 숫자)

| 구분 | 값 | 출처 |
|------|-----|------|
| 발단 사건 | (1줄: 무엇이 언제 어떻게 관측·요청됐나) | |
| 문제 규모 | (정량: N/M, %, 시간, 비용) | |
| 사용자 영향 증거 | (상관 관측 또는 직접 측정. 상관이면 "상관"이라고 표기) | |
| 원인 귀속 증거 1 | | |
| 원인 귀속 증거 2 | | |
| 원인 귀속 증거 N | | |
| 검토한 선택지 | (채택 1 + 기각 N, 기각 이유 각 1줄) | |
| 채택값의 역산 근거 | (왜 그 값·그 범위인가) | |
| 검증 방법 | (실험·재현·before/after, 사전 등록 기준이 있으면 기재) | |
| 결과 (정량) | before → after | |
| 비용 | 월 $ 또는 시간 | |
| 리스크 · 롤백 | blast radius, 되돌리는 방법과 소요 시간 | |
| **미완료 · 미측정** | (취약점 재료. 반드시 채운다. 없으면 "없음"이라고 명시) | |
| **방향 전환 · 오독 이력** | (hook 재료. 틀렸다가 고친 것, 순서를 바꾼 것) | |
| 팀에 남긴 것 | 문서·표준·알럿·런북 | |
