## Recommend 모드: 도메인별 학습 주제 추천

학습 주제·로드맵 추천 요청은 /learn:explore가 받는다. 이 모드는 /learn 세션 중 다음 주제를 이어서 고를 때만 쓴다.

Phase 0에서 Recommend 모드로 분기된 경우 이 섹션을 따른다.
목표: 시니어/스태프 엔지니어 성장에 필요한 학습 주제를 도메인별로 구조화하여 추천한다.

### 핵심 원칙

- **시니어/스태프 관점**: 단순 사용법이 아닌, 설계 철학·내부 동작·트레이드오프를 이해하는 주제 위주
- **Why-first 추천**: 각 주제가 왜 시니어/스태프에게 중요한지 근거를 명시
- **의존성 기반 순서**: 선수 지식 → 핵심 → 심화 순서로 학습 경로 제시

### 진행 절차

1. **도메인 파악**: 사용자 메시지에서 도메인 추출 (예: "AWS network", "Kubernetes", "Observability")
2. **수준 파악**: 해당 도메인에 대한 현재 수준 확인 (easy / medium / hard)
   - 대화에서 이미 명확하면 생략
3. **주제 분석 & 추천 출력**: 아래 출력 형식에 따라 구조화된 추천 제공
4. **세션 전환**: 사용자가 번호를 선택하면 해당 주제로 Phase 0 (Deep-dive 모드)부터 시작

### 주제 분류 체계

추천 주제를 3개 레이어로 분류한다:

| 레이어 | 설명 | 시니어/스태프 관점 |
|--------|------|-------------------|
| **Foundation** | 선수 지식, 기초 원리 | "왜 이렇게 동작하는지" 설명 가능해야 함 |
| **Core** | 도메인 핵심 기술 | 설계 의사결정을 내릴 수 있어야 함 |
| **Advanced** | 심화/최적화/엣지케이스 | 팀의 기술 방향을 리드할 수 있어야 함 |

### 출력 형식

```
## {domain} 학습 추천 (시니어/스태프 관점)

### 현재 수준
- Level: {easy | medium | hard}
- 도메인: {domain}

### Foundation: 기초 원리
| # | 주제 | 난이도 | 시니어/스태프에게 중요한 이유 |
|---|------|--------|---------------------------|
| 1 | {topic} | {level} | {왜 이 주제를 알아야 하는지} |

### Core: 핵심 기술
| # | 주제 | 난이도 | 시니어/스태프에게 중요한 이유 |
|---|------|--------|---------------------------|
| 1 | {topic} | {level} | {왜 이 주제를 알아야 하는지} |

### Advanced: 심화/리더십
| # | 주제 | 난이도 | 시니어/스태프에게 중요한 이유 |
|---|------|--------|---------------------------|
| 1 | {topic} | {level} | {왜 이 주제를 알아야 하는지} |

### 학습 순서 가이드
{의존성 관계와 추천 학습 순서를 화살표로 표현}

```
[Foundation A] → [Core B] → [Advanced C]
       ↘ [Core D] → [Advanced E]
```

> 번호를 선택하면 해당 주제로 Deep-dive 학습 세션을 시작합니다.
> "전체 커리어 관점에서 뭘 공부해야 할지"는 `/learn:growth-maker`를 사용하세요.
```

### 수준별 추천 범위

| 수준 | Foundation | Core | Advanced |
|------|-----------|------|----------|
| easy | 3-4개 (상세 설명) | 2-3개 (개요) | 1개 (존재만 언급) |
| medium | 2개 (빠르게) | 3-4개 (상세) | 2-3개 (개요) |
| hard | 1개 (복습용) | 2-3개 | 3-4개 (상세) |
